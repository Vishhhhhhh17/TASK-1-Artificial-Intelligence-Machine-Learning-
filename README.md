# TASK-1-Artificial-Intelligence-Machine-Learning-

This repository contains Task 1 of my AI & ML Internship, which focuses on understanding a dataset and analyzing its structure before applying any machine learning models.

In this task, I worked with the Titanic dataset to explore and understand the data by:

Loading and inspecting the dataset

Identifying different types of features (numerical, categorical, ordinal, and binary)

Checking unique values and data distribution in categorical columns

Identifying the target variable and relevant input features

Analyzing dataset size and suitability for machine learning

Detecting data quality issues such as missing values and class imbalance

The analysis was performed using Python, mainly with the Pandas and NumPy libraries, in Google Colab
